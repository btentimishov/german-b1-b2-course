Action or description?

After could, use an action verb directly. Add be when the next word describes a person, thing, or situation.

Action · действие

could + verb

couldtravel / sleep / drive

We could travel.
The baby could sleep comfortably.

могли путешествовать · мог спать комфортно

Description · описание

could + be + adjective

couldbeflexible / comfortable

We could be flexible.
The journey could be comfortable.

могли быть гибкими · могла быть комфортной
