# Deutsch im echten Leben · B1–B2

An interactive German course focused on practical communication, articles, vocabulary, and grammar for everyday life and work in Germany.

The public course is delivered through GitHub Pages. Each lesson is a self-contained HTML page with immediate browser feedback and a copyable learning report for adaptive follow-up lessons. Progress, review dates, and recurring mistakes are stored locally in the learner's browser; no account or server is required.

## Public content

- `index.html` — course homepage
- `lessons/` — interactive lessons
- `reference/` — printable cheat sheets
- `assets/` — shared styles and interactions

The learner's private notes and learning records are intentionally excluded from the public repository.
